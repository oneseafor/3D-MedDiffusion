### 2.8 num_classes 不匹配问题根因分析

**根本原因：代码执行顺序问题**

**代码位置：** `train_BiFlowNet_SingleRes.py`

```python
# 第 170-181 行：模型初始化（使用 args.num_classes 默认值 7）
model = BiFlowNet(
    ...
    cond_classes=args.num_classes,  # 此时 args.num_classes = 7（默认值）
    ...
)

# 第 259 行：更新 args.num_classes（但模型已初始化）
args.num_classes = len(cardiac_config["data"]["disease_categories"])  # 更新为 5
```

**执行顺序：**
1. 模型初始化 → 用默认值 7
2. 加载配置 → 更新 `args.num_classes` 为 5
3. 训练 → 模型结构是 7 个类别，但只用 5 个类别训练

**结果：**
- 模型结构：`cond_emb.weight` 形状 `[7, 288]`（7 个类别）
- 训练时：只使用前 5 个类别（0-4）
- 生成的 sample：只有 `_0, _1, _2, _3, _4`（因为 `args.num_classes` 被更新为 5）

**结论：** 生成时必须用 `--num-classes 7`（匹配模型结构），但只使用前 5 个疾病类别

**为什么之前没有发现这个 bug？**

| 原因 | 说明 |
|------|------|
| **不会导致训练报错** | 模型用 7 个类别初始化，训练时只用 5 个，不会报错 |
| **优先修复阻塞性问题** | 之前修复的都是导致训练失败的错误（维度不匹配、路径错误等） |
| **代码审查疏漏** | 没有检查模型初始化和配置加载的执行顺序 |

**之前的修复都是阻塞性问题：**
- Latent 目录路径错误 → 训练无法启动
- 路径后缀重复 → 数据加载失败
- 维度不匹配 → 运行时报错
- einops 错误 → 运行时报错

**而 num_classes 问题：**
- 训练可以正常进行
- 只是模型结构和实际使用不匹配
- 直到生成阶段才暴露出来

### 2.9 修复 decode_sliding 维度错误

**问题：** `decode_sliding` 函数默认 `compress_ratio=8`，`latent_patch_size=32`，但心脏 MRI 的 D=25，无法进行 unfold 操作

**错误信息：**
```
RuntimeError: maximum size for tensor at dimension 2 is 25 but size is 32
```

**修复：** 修改 `generate_cardiac_synthetic.py`，使用 `AE.decode()` 替代 `AE.decode_sliding()`

**原因：** 心脏 MRI 的 latent 大小是 `(25, 32, 32)`，D 维度只有 25，不是 8 的倍数，无法使用滑动窗口解码

```python
z = torch.randn(1, 8, 25, 16, 16)  # patch 模式

```

**模型权重来源：**

| 组件 | 来源 | 作用 |
|------|------|------|
| BiFlowNet EMA | 0367350.pt | 从噪声生成 latent |
| AutoEncoder | Stage 2 checkpoint | 将 latent 解码为图像 |

**输出格式：**

| 模式 | Latent 大小 | 输出大小 | 说明 |
|------|-------------|----------|------|
| patch | [8, 25, 16, 16] | [1, 25, 128, 128] | 直接 decode |
| full | [8, 25, 32, 32] | [1, 25, 256, 256] | decode_sliding |

**数据流：**
```
随机噪声 z (8×25×16×16)
    ↓ BiFlowNet EMA 反向扩散
Latent (8×25×16×16)
    ↓ 反归一化
Latent (codebook 范围)
    ↓ AE.decode() 或 AE.decode_sliding()
合成 MRI (1×25×128×128 或 1×25×256×256)
    ↓ 转置维度
保存为 NIfTI (H×W×D)
```

**与训练数据的关系：**
- 训练时：原始数据 → AE 编码 → latent → BiFlowNet 学习 latent 分布
- 生成时：随机噪声 → BiFlowNet 生成 latent → AE 解码 → 合成数据
- **生成的 latent 是模型学到的分布中采样，不直接来自训练数据**
